# Development Rules

* Do not create, modify, or delete any README files.
* Do not create, modify, or delete any test cases or test files.
* Do not add test-related code.
* Do not modify existing tests.
* Only modify files required for the requested feature.
* Follow the existing project architecture and coding patterns.
* Reuse existing models, schemas, services, utilities, and dependencies.
* Do not refactor unrelated code.
* Do not change existing behavior unless explicitly requested.
* Keep the implementation clean, minimal, and focused on the requested task.
